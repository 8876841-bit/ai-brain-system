## 四个阶段

### 阶段一：大模型基础（Day 1-10）
Token → Embedding → Self-Attention → QKV → PyTorch → Mini Transformer → 残差连接 → LayerNorm → Tokenizer → KV Cache → 采样策略 → 第一阶段复盘

### 阶段二：Agent 基础机制（Day 11-21）
Messages → API Payload → 上下文管理 → System Prompt → Few-Shot → Function Calling → Tool Runtime → RAG索引 → RAG问答链路 → ReAct Loop → Memory → Agent Eval

### 阶段三：多Agent与工具化架构（Day 22-30）
个人助理Agent v1 → Orchestrator-Worker → Subagent设计 → Skill Registry → 感知-推理-执行 → LangGraph → 多Agent阶段复盘

### 阶段四：AI编程与项目落地（Day 31-40）
AI编程工具 → Vibe Coding → 毕业项目PRD → 架构 → 核心链路 → 日志与Trace → 垂直应用复盘
