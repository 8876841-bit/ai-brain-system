# 碎片知识管理——三步法

## 来源
抖音私信分析 / 小常

## 核心问题
每天刷到大量零散信息，记了但不成体系、容易遗忘、难以调用，最终变成信息焦虑而非知识积累。

## 三步法

### 第一步：分类（贴标签）
每条内容打1-3个标签，不超过3个。
标签口语化，比如用"#说话不冷场"而不是"#人际沟通技巧"。

### 第二步：加工（让碎片变厚）
对每条知识问4个问题：

| 问题 | 目的 |
|---|---|
| 它是什么？ | 明确核心定义 |
| 它为什么重要？ | 找到学习意义 |
| 它怎么用？ | 找到应用场景 |
| 它和我有什么关系？ | 建立个人关联 |

**第4个问题最重要。** 没有个人关联的知识留不住。

### 第三步：应用
- 定期回顾，把碎片归入已有框架
- 输出倒逼输入：整理成内容，检验是否真正理解
- 遇到问题时主动检索，而不是重新搜索

## 与第二大脑系统的关系

这三步对应我系统里的：
- 第一步 → 我为什么存它（标签/分类）
- 第二步 → `00_Inbox` 处理时的加工动作
- 第三步 → 提炼进 `05_Insights` 或 `09_Models`，最终变成内容

**关键补充**：核心在于第二步的加工，而不是第一步的分类。大多数人在第一步就停了。
