# 部署与工作流所需知识

来自 5.27 日记的问题：部署模型和搭建工作流，一定要有Python基础吗？

---

## 结论

需要，但门槛没那么高。

---

## 最低限度需要掌握的

| 知识点 | 具体内容 |
|--------|---------|
| 基础Python语法 | 变量、函数、if/for，能读懂别人的代码就够 |
| pip和包管理 | 知道怎么安装依赖（`pip install xxx`） |
| 环境变量 | 知道怎么设置API Key（`.env`文件） |
| 基本终端操作 | cd、运行脚本（`python xxx.py`） |

---

## 不需要

- 从零写复杂逻辑
- 深度算法知识
- 框架源码理解

---

## 实际操作方式

大部分工作流 = 调用现成API + 连接节点

Claude Code可以帮你生成代码，你负责：
1. 看懂逻辑
2. 调整参数
3. 判断结果是否符合预期

这是 Vibe Coding 的核心——人定方向和验收标准，AI负责生成和执行。

---

## 学习进度（更新于 6.1）

**触发原因**：网站工具效率低、答复质量弱，专业陪跑指出根本问题是**缺知识库**，建议先掌握Python基础。

**学习方式**：从编程历史切入，不死记语法。
- 路径：汇编语言 → C语言 → Python → 现代框架
- 理解"为什么这样演变"，语法就有了逻辑可循

**当前状态**：
- ✅ 了解编程发展历史
- ✅ 认识Python里的固定格式/语法结构
- ⬜ 实操练习（还没开始）

**下一步**：补知识库 → 这是让工具从"通用回答"变成"有针对性回答"的关键。
