# 如何获得结构理解 + 表达 + 系统整合能力

## 你的问题
- 如何获得这种能力？
- 需要哪些技能？
- 在什么场景下使用？

## 当前理解

**结构理解**：看一个东西，能说出它底层的逻辑是什么——不是看表面，是看原因。
**表达**：把这个逻辑讲成别人能接收的形式。
**系统整合**：把多个理解连起来，变成可以反复用的框架。

**用我自己的工作举例**：
- 结构理解：看完一个家，能说出"这个空间好用的底层原因是动线只有一条，收纳全部隐藏"
- 表达：把这个逻辑拍成视频，让从没装修过的人看完也理解
- 系统整合：把"为什么这个家好"变成可以用在下10个案例的框架

## 怎么培养

每次遇到一个好的东西，不要只说"这个好"，问自己"它好在哪个结构上"。养成这个追问习惯。
