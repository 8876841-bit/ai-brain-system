# 如何使用这个仓库

## 仓库定位
这个仓库不是资料库，而是我的认知系统仓库。

它的目标是把零散输入转化为：
- 问题
- 洞察
- 方法
- 模型
- 行动判断

## 使用流程
输入 → 分类 → 追问 → 提炼 → 建模 → 反用

## 每天
处理 1–3 条 Inbox 内容。

每条内容回答：
1. 这是什么？
2. 我为什么记录它？
3. 它属于哪个分类？
4. 它现在是问题、洞察，还是模型？
5. 下一步是什么？

## 每周
做一次认知复盘：
- 本周反复出现的问题
- 本周新增洞察
- 哪些可以继续研究
- 哪些可以升级成模型

## 每月
回答三个问题：
- 我是谁？
- 我正在往哪里走？
- 下个月集中打哪一个能力？

## 核心原则
不要追求文件多。
不要把仓库变成资料垃圾桶。
只有能帮助我理解、表达、判断、行动的内容，才值得沉淀。
