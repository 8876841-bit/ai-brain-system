# 临港路演观察：垂直行业与知识库

来自 6.2 日记，参加临港黑松克决赛路演的现场观察。

---

## 观察到的共同结构

现场所有厉害的开发团队，产品框架里都有两个板块：

1. **知识库** — 对应 RAG，领域专属数据的存储和检索
2. **历史沉淀** — 对应 Memory，随时间积累的上下文记忆

这不是巧合，这是 Agent 系统的标配。在实际产品里，这两个东西决定了产品"够不够懂这个行业"。

---

## 他们在做什么

覆盖行业：股票、投票、焊接、投资等垂直领域。

特点：对不同 API 的调用非常灵活，全部集合在一个页面，完善度高。

---

## 这个观察和自己的关联

"似懂非懂" = 框架在，细节还没填满。这是正常的学习阶段。

更重要的是：那些团队做的都是**垂直行业**。每个产品背后都有一个领域的真实数据和经验。

**你有家装木作行业的真实数据和经验，这就是你的垂直。**

从客户需求、到工厂下单、到案例内容，这些数据别人没有，你有。

---

## 外围的 OPC 产品展示

路演外围还有很多个人产品展示，新鲜、新颖。说明一个人也可以做出有价值的垂直产品。
