# 路径模式（Path Pattern）

## 所属模型层
Pattern

## 原始想法
看人不能只看表面，要看路径模式

## 你的意图
从人物中提取“可迁移的成长路径”

## 关键问题
- 什么是路径模式？
- 哪些是可迁移的？
- 哪些是不可复制的？

## 答案

**路径模式是什么**：看一个人不是看他做了什么，而是看他在什么时机做了什么别人没做的选择。不是结果，是选择逻辑。

**为什么重要**：表面信息（他去了好学校、进了好公司）没有迁移价值。路径模式才有——它告诉你在同样的岔路口，他为什么那样选，你该怎么判断。

## 两个案例

**Karpathy的路径模式**：两次主动放弃顶级职位去做教育。在"钱/地位"和"真正想做的事"之间每次选后者。

**Andrew Ng的路径模式**：把最值钱的知识免费给出去，用规模换影响力。反直觉，但建立了别人无法复制的位置。

## 如何迁移到自己身上

不是问"我能不能像他们一样"，而是问：
> 我现在面前有没有一个看起来不划算，但我觉得对的选择？

路径模式的本质：在别人看不懂的时候先押注。

## 我的路径模式雏形
开木作工作室 + 学AI + 做自媒体 = 没有人同时做这三件事。这是非线性组合，看起来分散，但如果做成了，位置是唯一的。
