# 多 Agent 架构与框架

来自 45 天学习计划 Day 23-30 的手写问题。

---

## 感知-推理-执行 三层架构

Agent 工作的完整循环：

| 层 | 作用 | 输入来源 |
|---|---|---|
| 感知 | 接收外部信息 | 用户输入、工具返回结果、RAG检索内容 |
| 推理 | 基于信息和目标决定下一步 | 上下文+目标 |
| 执行 | 调用工具、生成回复、更新记忆 | 推理结果 |

这三层循环运行，直到任务完成。ReAct Loop 是这个架构的具体实现方式。

## LangGraph vs AutoGen vs CrewAI

| 框架 | 适合场景 | 特点 |
|------|---------|------|
| **LangGraph** | 需要自定义状态流转的复杂 Agent | 灵活，可控，需要更多代码 |
| **AutoGen** | 多个 AI Agent 互相对话协作 | 微软出品，对话型多Agent |
| **CrewAI** | 角色分工明确的团队型任务 | 简单易上手，定义"角色"和"任务" |

**初学建议：**
45 天课程重点讲 LangGraph。先掌握 LangGraph，再看其他框架就容易理解了。

## Orchestrator-Worker 架构

- **Orchestrator**：总指挥，负责拆分任务、分配给 Worker、汇总结果
- **Worker**：执行者，专注完成具体的子任务

类比：你是 Orchestrator（负责框架和分工），合伙人是 Worker（负责执行落地）。

---

## Vibe Coding 人 / AI 分工

**人负责：**
- 定义目标
- 设定边界
- 制定验收标准
- 最终判断

**AI 负责：**
- 生成方案
- 修改代码
- 解释逻辑
- 查阅资料 / 运行测试
- 加速迭代

核心原则：人定方向，AI 搭建和执行。这和你们工作室的分工逻辑是一样的。
