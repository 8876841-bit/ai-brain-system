# AI Agent 底层原理

## 来源
抖音私信分析 / 学习AI的1000天

## 一句话定义
能理解目标、自主规划、调用工具、持续执行任务的智能系统。

和传统AI的区别：传统AI是一次性问答，Agent是多轮循环+自主决策。

## 五大核心模块

| 模块 | 作用 | 类比 |
|---|---|---|
| LLM Core | 理解意图、推理决策 | 大脑 |
| Memory | 短期/长期记忆积累 | 海马体 |
| Planning | 任务拆解、规划步骤 | 前额叶 |
| Tools | 调用外部能力 | 手脚 |
| Action | 输出结果、执行反馈 | 嘴巴 |

## 记忆系统三层架构

- **短期记忆**：本次会话上下文
- **长期记忆**：语义记忆（结构化知识）+ 情景记忆（过往经历）
- **程序记忆**：Agent的行为模式/SOP

## 两个关键协议

- **MCP（Model Context Protocol）**：帮助Agent获取外部环境信息，类似USB接口
- **A2A（Agent to Agent）**：定义Agent之间的消息格式，实现多Agent实时同步

## 思维模式：ReAct

推理（Reason）与行动（Act）交替循环：
```
Thought → Action → Observation → Thought → ...
```
不是一步到位，是不断反馈修正。

## 与我的关联

我用Claude Code本质上就是在用一个Agent——它有记忆（上下文）、有工具（读写文件/搜索）、有规划（多步任务）、有执行（写代码/推仓库）。

理解这个结构，能帮我更好地设计给它的任务，而不是把它当一个聊天框用。
