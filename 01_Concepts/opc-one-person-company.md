# OPC — 一人公司模式

## 来源
抖音私信分析 / Anton Coding — 用Hermes成交第一个OPC项目

## 定义
**OPC（Operator Personal Company）**：一个人借助多个AI Agent实现自动化运营，达到一家公司的产出规模。

核心逻辑：**1个人 + 多个AI Agent = 公司级产出**

## 与我的关联

这不是一个遥远的概念，这是我现在的实际形态：

- 我 = 决策者 + 框架搭建者
- 合伙人 = 执行者 + 客户对接
- Claude = 内容生产系统
- 仓库 = 可复用的知识资产

当内容系统跑通、案例积累足够多，这个组合本身就是一个OPC。

## 核心问题
- 我的"AI Agent团队"现在承担了哪些角色？
- 哪些环节还是靠人工重复做，可以用Agent替代？
- 一个完整的OPC内容公司，应该有哪些角色分工？
